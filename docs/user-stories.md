# User Stories

1. As a user, I want a list of satellites I'm interested in, so the passes I see are only ones I actually care about.
2. As a user, I want to share my location, so I can see what's visible from where I currently am.
3. As a user, I want to input a location instead of sharing it, so I don't have to give my actual location.
4. As a user, I want to be notified before a satellite I follow passes over me, so I have time to go outside and find a good spot.
5. As a user, I want to know what cardinal direction the satellite is coming from, so I know where to look.
6. As a user, I want to create an account, so my location and satellite list are saved and I don't set everything up again each visit.
7. As a user, I want to change my location, so I can see what's visible when I go camping.
8. As a user, I want to see upcoming passes for the satellites I follow when I open the app, so I immediately know whether there's anything to go outside for.
9. As a user, when there are no visible passes coming up, I want the app to tell me clearly, so I know it checked and there's genuinely nothing.
10. As a user, I want each pass to show the date, start time, and duration, so I can decide whether it's worth going out for.
11. As a user, I want to remove a satellite from my list, so I stop getting passes and notifications for something I've lost interest in.

## Happy Path

1. User opens the app.
2. App prompts to create an account or sign in.
3. User creates an account.
4. App recommends which satellites to follow.
5. User searches or selects satellites for their favorites list.
6. App asks for location sharing permission.
7. User grants it.
8. App displays a week overview of which satellites are visible on which days.
9. User clicks a day.
10. App lists all followed satellites visible at that location that day, ordered by start time.
11. User clicks a satellite.
12. App shows pass info (start, end, duration).
13. User taps "notify me before this pass."
14. App asks notification permission.
15. User grants it.
16. Later that evening, notification arrives ~15-20 min before the pass.
17. User goes outside, looks northwest, watches it cross the sky.
